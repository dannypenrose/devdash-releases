# DevDash releases

Installers for [DevDash](https://devdash.axiomstudio.io), your local dev
environment in one window: macOS (Apple Silicon and Intel), Windows and Linux.

Download the latest version from the
[Releases](https://github.com/dannypenrose/devdash-releases/releases/latest) page.
DevDash updates itself from here once installed.

This repository holds release files only; the source is private.
